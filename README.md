# La Vanilla SaaS Platform

Enterprise cloud platform and analytics dashboard designed for scalable business intelligence, real-time data streaming, and automated workflow management.

## Features
- Real-time analytics dashboard with interactive data visualization.
- Secure JWT authentication and role-based access control (RBAC).
- Stripe payment gateway integration for automated billing.
- Responsive design optimized for desktop and mobile viewports.

## Tech Stack
- **Frontend:** React, Tailwind CSS, Lucide Icons
- **State Management:** Context API & Custom Hooks
- **Build Tool:** Vite / Webpack
